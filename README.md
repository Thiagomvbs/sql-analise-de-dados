📊 Análise de Dados de Vendas com SQL
📌 Sobre o Projeto

Este projeto consiste em uma análise exploratória de dados de vendas utilizando SQL.
O objetivo foi extrair informações estratégicas a partir de uma base relacional, identificar tendências ao longo do tempo e desenvolver métricas de acompanhamento de desempenho por categoria e fornecedor.

A partir das consultas SQL, os dados foram exportados para o Google Sheets para criação de visualizações gráficas e consolidação do relatório final.

🎯 Objetivos da Análise

- Identificar a categoria que mais vendeu em 2022

- Descobrir as duas categorias com maior volume de vendas no histórico total

- Comparar a evolução temporal das categorias líderes

- Analisar desempenho de fornecedores ao longo do tempo

- Calcular a participação percentual de vendas por categoria

- Criar uma métrica comparativa entre a melhor e a pior categoria em 2022

🛠 Tecnologias Utilizadas

SQL (SQLite)

Google Sheets (visualização de dados)

GitHub (versionamento)

Markdown (documentação)
